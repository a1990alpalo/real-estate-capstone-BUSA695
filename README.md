# real-estate-capstone-BUSA695
Capstone project analyzing USA real estate data using Python and machine learning

🏠 Real Estate Capstone Project (BUSA 695)
📌 Overview

This project analyzes a USA real estate dataset to identify the main factors that influence housing prices and to build predictive models.

🎯 Business Question

Which variables have the strongest impact on housing prices, and how can they be used to predict property values?

🧹 Data Preparation
Handled missing values using median imputation
Removed outliers
Converted data types
Encoded categorical variables
🤖 Modeling
Linear Regression (multiple models tested)
Random Forest (improved performance)
📈 Results
Linear models: low R² (~0.03–0.07)
Random Forest: improved R² (~0.25)
